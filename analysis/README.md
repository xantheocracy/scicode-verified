# Paper analysis artifacts

Machine-generated statistics behind the SciCode-Verified paper, released for
reproducibility. Copied verbatim from the paper workspace; the generator scripts
document the exact counting rules in their docstrings.

| File | What it is |
|---|---|
| `defects.json` | The 264-defect ledger-derived taxonomy (problem, step, fields_involved, direction, rationale). |
| `flawed_steps.json` | Per-subproblem flaw list derived from `defects.json`: 155/287 scored subproblems (58/64 problems) touched by a score-suppressing defect; 71 subproblems where tests/gold themselves are wrong. Generated by `make_flawed_steps.py`. |
| `flips.json` | Per-model fail→pass / pass→fail step sets between the original-benchmark run (orig1) and the corrected-benchmark run (run4) for GPT-5.5, Gemini 3.5 Flash, Claude Opus 4.8, GLM-5.2; union/intersection included. |
| `or_gain.json` | Per-model steps whose verdict multi-environment OR grading changes vs the 2024 stack alone (7–9 per model), with error text and whole-problem effects; extracted from the per-step grading caches. |
| `regrade_summary.json` | Fixed-output re-grading: each model's original-run generations re-scored, unchanged, against the corrected tests/gold. Separates the grading-layer share (20–35% of the step gain) from the specification-layer share. |

The generator scripts reference the evaluation-run folders (`eval_clean/ds_runs/`)
which contain per-step raw outputs and are not committed wholesale; the JSON
outputs above are the canonical numbers cited in the paper.
