## Summary
13.9 `derivatives` computes the inner-boundary (octant) symmetry of the fields for a
z-axis magnetic-dipole configuration. The **gold/target applies parity `(+,+,-)` to
`A_z`** on the x=0 and y=0 inner faces. That **violates the vector-transformation
constraint** that the three components of the single polar vector **A** must obey.
The correct parity is **`A_z = (-,-,-)`**. This single sign error makes 13.9 — and the
whole time-evolution cascade 13.10, 13.11, 13.12, 13.13, 13.15 (all call `derivatives`)
— **unsolvable by any model**. It is NOT a prompt under-specification and NOT a model
error; it is a **gold/target defect** in the original SciCode reference.

## The vector constraint (why gold is wrong)
A is one polar vector; under a mirror only the component normal to the plane flips sign,
so the parities of A_x,A_y,A_z are coupled:
- x=0 reflection flips only A_x ⇒ **A_y and A_z share the same x-parity** (A_x opposite).
- y=0 reflection flips only A_y ⇒ **A_x and A_z share the same y-parity** (A_y opposite).
- z=0 reflection flips only A_z ⇒ A_x and A_y share z-parity (A_z opposite).

From the gold-confirmed `A_x=(+,-,+)`, `A_y=(-,+,+)` ⇒ A_z must be
`(x = A_y's x = -, y = A_x's y = -, z = opposite of A_x/A_y's + = -)` = **`(-,-,-)`**.
Gold's `(+,+,-)` breaks the x and y constraints (A_z x-parity ≠ A_y's; A_z y-parity ≠ A_x's).

**Cross-check** (proves the principle, isolates the lone violator): E (also a polar
vector) `E_x=(+,-,+), E_y=(-,+,+), E_z=(-,-,-)` satisfies all three constraints; phi
(scalar) `(-,-,+)` is consistent. The configuration symmetry σ=(-1,-1,+1) is clean across
E and phi — **only gold's A_z violates it.**

## R5 — cascade RESOLVED by test redesign (13.11 / 13.12 / 13.13 / 13.15)
The over-specification above is fixed not by recovering gold's exact ICN scheme but by
**redesigning the tests at the input level** (user: "如果输入都是 unphysical 的就从输入改,不要将就").
Design: `docs/superpowers/specs/2026-06-24-p13-evolution-test-redesign-design.md`.

- **Principle.** Physically-meaningful, divergence-free inputs + a CONVERGED numerical
  reference (RK4 @ ref_courant=0.05, correct parities incl. the R4 A_z fix) + a TIGHT atol
  that EQUALS the algorithm's own 2nd-order convergence error (user: "atol 就是算法的误差范围,
  不要设的太宽"). test_courant=0.02 is small enough that any stable 2nd-order ICN converges to
  the reference; the 13.11 spec ("advance maxwell.t by t_const") makes a compliant stepper
  land EXACTLY at t_const, so the only residual is scheme-order error.
- **Two configs** (both σ=(-1,-1,1)): config1 = toroidal magnetic-dipole pulse
  (E_x=8y e^-r², E_y=-8x e^-r², rest 0) — exercises x–y evolution, develops only a small E_z;
  config2 = config1 + A_z = 8·xyz·e^-r² — drives a DOMINANT E_z, making the A_z/E_z parity
  testable. Calibration (`analysis/_p13_code/_calib_R5.log`, n=64): field FLOOR (max over
  rk2/icn2/icn3) ≈ 2.9e-5 at t=0.2; the parity bug on config2 = **0.42** (margin ≈ 1.4e4×),
  sign-flip ≈ 5e2. atol frozen = 1.5× the global floor.
- **Per step.** 13.11 `stepper`: evolve {config1,config2} to t_stepper=0.2, compare final
  7-field state to the reference within atol. 13.13 `integrate`: integrate {config1,config2}
  to t_max=0.5, compare the in-place final field within atol + assert the returned constraint
  series is finite & bounded. 13.15 `main`: dipole at the test grid; compare the returned
  constraint series within atol_series (the ‖div E‖ operator amplifies field error, so its own
  tight tolerance — measured series floor ≈ 1.4e-7). 13.12 `check_constraint`: DECOUPLED from
  the stepper — directly set E (dipole div-free; linear E=(x,y,z) → div=3) and compare the
  deterministic ‖div E‖ exactly (atol=1e-9).
- **13.15 docstring** also corrected: `main` returns a 1-D ndarray series (matching gold's flat
  array + `integrate`), not the "list of tuples" the original docstring wrongly claimed.
